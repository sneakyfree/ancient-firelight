# Ancient Firelight

Faceless YouTube channel — the long dawn of the human mind.

## The one rule
Promise a vanished world. Deliver the mechanism as payload, never as the promise.
(David Reich on Dwarkesh, same guest/channel: "How one small tribe conquered the world 70,000 years ago" = 2,004,761 views. "The Cost our Ancestors Paid for Intelligence" = 30,457. 66x, packaging only.)

## Never say
- "sentient" when you mean **sapient** (animals are sentient; Homo sapiens = wise man)
- "cavemen" — the winners say **ancient humans**
- "they did nothing for 200,000 years" — say **the fire kept almost catching**

## Layout
- `scripts/` — one .md per episode, with shot column
- `assets/cast/` — hand-drawn stick puppets (NEVER AI-generated; consistency by construction)
- `assets/world/` — 5090 / style-LoRA output: backgrounds, props, megafauna, maps
- `assets/thumbs/`
- `voice/` — narration takes
- `research/` — per-episode source briefs
